## Included

Each date package should contain only curated research material:

```text
report_card.md
meeting_brief.md or meeting_brief_cn.md
summary.md / detailed.md / protocol.md when copied directly
source or theory notes when explicitly used by the package
figures/
tables/
```

## Excluded

```text

checkpoints
datasets
full run directories
private daily notes
experiment code workspaces
unrelated old sync copies
```
