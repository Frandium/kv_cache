# 从频谱偏置到功能路由：covariance 频带能否成为分发原则？

状态：组会收束；A15 的频谱访问、学习动力学、固定频带功能准入与 common/residual 审计均已完成。下一缺口是不同层的特定频带分别编码什么信息。

## 1. 本次回答的问题

**问题：** 为什么线性 Gate 的学习受到 covariance head 支配；这种偏置是否已经足以指导 Router 设计？

**术语：** head、middle、tail 是每层 Router 输入中，按 covariance 特征值从大到小排列的方向区间。它们只表示该层内变化量的相对大小，不天然表示语义层级或功能重要性；不同层的同名频带也不等于编码相同信息。

## 2. 认识更新

**一句话回答：** 大方差使线性 Gate 在有限训练时间内更快学到 head；但 head 主导首先是优化偏置，不等于该划分最有利于专家训练。

1. 训练后的 Gate 在等能比较下仍明显偏 head；middle/tail 的响应不为零，也会改变部分原生路由，因此不是“线性 Gate 完全看不到 non-head”。
2. 受控实验给出因果解释：目标和总能量相同时，方向方差越大，Gate 达到相同学习进度越快；把各方向重新缩放到等方差后，速度差消失；tail 单独承载目标时仍可学会。
3. Middle、tail 与二者联合确实产生 native Router 分数之外的新邻域，但同维随机子空间也产生相近程度的新邻域；这些频带没有跨 LB/decommon 稳定预测哪些 token 共同训练更兼容。
4. decommon 只移除了均值，没有移除去均值后仍跨文档共享的 centered covariance head。centered top-64 与更深 residual-64 的 projector 都高度重合，但 Gate 对前者的等能响应仍约强 2.8--4.6 倍。
5. 因此，“让浅层指导后层”目前不是结论。不同层经历了不同计算，同为 head 或 middle 的频带可能编码不同变量；必须先测清每层某个特定频带编码什么、前层已经解决了什么，才能判断它是否应成为后层分发条件。

## 3. 决定性证据

| 证据层级 | 关键结果 | 能回答什么 |
| --- | --- | --- |
| Gate 频带响应 | 等能 head:middle 为 4.03--6.36 倍，head:tail 为 14.61--25.36 倍；non-head 响应非零 | Gate 可访问全谱，但明显偏 head |
| 学习动力学 | 等方差时 H/M/T 学习时间约 1:1:1；方差为 4:2:1、16:4:1 时约为 1:2:4、1:4:16；重新等方差后回到 1:1:1 | 大方差因果加速线性 Gate 学习 |
| 固定频带功能准入 | 真实频带更换 73%--90% 的邻居，随机同维也更换 71%--88%；M/T/M+T 均未跨两条谱系通过兼容性门 | 新划分不等于有益划分 |
| 去均值后的结构 | common/residual projector overlap 为 0.76--0.79/0.70--0.73，随机 q95 约 0.09；Gate 仍更偏 common | 去均值没有消除稳定 head，residual 也不是随机噪声 |

**读表结论：** 频谱解释了 Router 为什么先学什么，却尚未告诉我们每层的这些方向在计算什么，也尚未给出功能路由原则。

## 5. 边界与 Next-to-do

- **成立范围：** 线性 Gate、已注册的受控 SGD 系统、LB/decommon 的 12 层 DCLM checkpoint，以及固定频带的一步共同训练兼容性测试。
- **仍不能说：** head 在语义上更重要；middle/tail 没有价值；深层必然更 compositional；某个浅层频带一定适合指导后层；概率树就是自然语言模型的真实内部结构。
- **最强 rival：** 深层频带看起来包含更多任务信息，可能只因为深层更接近输出；特定频带的优势也可能由任意同维子空间复现，而非层级计算。
- **唯一下一决策：** 用 A14 的条件概率树作为可控数据模型，训练一个通过组合能力门的四层小网络，并在冻结 checkpoint 上建立“层 × 频带 × 信息类型”矩阵。信息真值至少包括粗条件、条件内细分和组合结果；训练见过全部原子，测试保留新组合，并设置长度、位置和难度匹配的一步控制。
- **测量原则：** 每层只在独立 calibration set 上离线分解一次，频谱是测量标尺而不是在线 Router。用相同容量、非饱和 probe 比较各层 H/M/T、同维随机子空间与完整表征；若画像跨种子复现，再学习固定的层别低秩 projector 或 prototype encoder，替代反复谱分解。
- **完成判据：** 小模型先通过未见组合能力门；随后至少有一种信息在特定“层 × 频带”中稳定超过同维随机与匹配一步控制。只有这一步通过，才把该层别功能坐标送入共同训练兼容性检验，再决定是否做跨层分发训练。
- **恢复时第一动作：** 在 compositional 对话中冻结概率树变量、合成数据、四层模型能力门和画像指标；不直接启动浅层指导后层的联合训练。
