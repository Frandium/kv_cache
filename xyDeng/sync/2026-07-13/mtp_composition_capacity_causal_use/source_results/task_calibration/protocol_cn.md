# Protocol：A11_23 组合学习校准

## 0. Approval Snapshot

用户已明确要求按顺序完成 planned anchors 并解决阻塞，因此本有界校准获准执行。唯一问题是：首个通过 seed-971 筛选的修复配置，能否在 5/5 seed 的独立 test 上达到答案准确率 `>=0.70`。主指标是五个 seed 最低 test 准确率。通过还要求格式准确率 `>=0.95`、跨 split 目标置换重叠为零、单表/打乱标签控制有效。该实验不能声称 MTP 有益、深度是唯一原因、容量或课程机制成立。

## 1. 术语

校准只判断任务/模型表面是否具备后续机制研究资格。seed 971 validation 用于有界筛选；冻结配置后，seeds `971--975` 从头训练并只用独立 test 判定。

## 2. 固定与改变

固定数据语义、155-token 序列、NTP 受控损失、AdamW `3e-4`、weight decay `0.01`、batch 64。按顺序只改变深度、训练预算、宽度。

## 3. 有界阶梯

`2L-64d-600 -> 2L-64d-3000 -> 3L-64d-3000 -> 3L-128d-3000`。首个 validation `>=0.70` 的条件立即冻结并做五 seed 确认；不允许结果后扩展。

## 4. 数据

从一个全局置换池互斥切分：train 8192、validation 1024、audit 1024、test 2048。只训练 full view；单表替换与标签打乱只用于控制。

## 5. 判定

$$
Q_{cal}=\min_s A_{answer,test}^{(s)}.
$$

`Q_cal>=0.70`、最低格式准确率 `>=0.95` 且所有守卫通过为支持；四级均失败为操作化失败；split 重叠、结果缺失或控制失效为证据不足。

## 6. 边界

校准成功只说明存在一个可学习配置。下一步仍需用独立 offset-2 head 复跑 A11_22，不能直接进入 MTP 收益结论。
