## Current Claim

M4 matrix response energy is the best current 2D static oracle metric. M3 top-1 projection is a plausible low-rank proxy. M1/M2 are useful direction baselines but are not the core expert-matrix geometry model.

The proof draft adds a sharper theoretical distinction: raw M4 does not guarantee 50/50 load for random Gaussian experts, centered M4 does in 2D, and M3 top-1 also has a 2D 50/50 proof when the two top direction lines are distinct.

## Boundary

This package does not claim that a trainable router learns M4, that high-dimensional centered M4 automatically gives balanced load, or that score advantage implies real task utility.

Raw logs, checkpoints, datasets, source code, and raw per-seed metric dumps are intentionally excluded.
