## Scope

This package records the full Round-2 dot-product common-logit audit. It tests whether common-logit dominance is early, predictive, and intervention-relevant for random-init sparse top-1 MoE collapse in the uniform no-position slot task.

## Boundary

The result supports common-logit dominance as a causal contributor to routing collapse in this toy dot-product top-1 setting. It does not prove full common-source identification, expert-computation specialization, real-language-model transfer, or a deployable router design.
